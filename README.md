# GCG Web Application

Official web application repository for **Govt. Graduate College for Boys, Satellite Town, Gujranwala**. Built using the MERN stack to manage college operations, faculty profiles, student admissions, notices, and events.

---

##  Tech Stack

* **Frontend:** React.js, Vite, Bootstrap, Axios
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose (ODM)
* **Authentication & Security:** JSON Web Token (JWT), Bcrypt.js

---

##  Key Features

* **Admin Dashboard:** Secure login and management interface for site administrators.
* **Faculty Directory:** Dynamic listings of college faculty members and department details.
* **Admissions & Notices:** Online application forms, fee structure details, and official announcements.
* **Events & Timetables:** Showcase for campus events, news updates, and class schedules.
